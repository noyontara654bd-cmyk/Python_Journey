# Python Journey 

This repository documents my step-by-step Python learning and problem-solving journey on **HackerRank**, covering foundational programming concepts and logic building.

## Programs & Concepts Covered

1. **`Python If-Else.py`:** Evaluates an integer using conditional statements (`if`, `elif`, `else`) to classify numbers as "Weird" or "Not Weird".
2. **`Arithmetic Operators.py`:** Performs basic arithmetic operations, including sum, difference, and product of two integers.
3. **`Python_ operators.py`:** Practices multiple mathematical operations such as averages, floor division (`//`), remainder (`%`), and exponentiation (`**`) on three numbers.
4. **`Loop.py`:** Uses `for` loops and `range()` to calculate squares, cubes, total sums, and even-number sums across a series.

---

## How to Run

1. Make sure **Python 3** is installed on your system.
2. Open your terminal or IDE (such as VS Code) and run any file using:
   ```bash
   python "Loop.py"
   ```
